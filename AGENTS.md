# Research rules

These rules apply whenever you are asked to research, compare, or find out something. They do not apply to drafting or editing help center topics. For those, follow `.bob/rules/rba-context.md`.

## Report only what sources say

- State only what the sources you found say. Do not add what you already know.
- If you did not find it in a source, do not state it.
- Read a source before you cite it. A search snippet is not a read source. Say which sources you read in full and which you saw only as excerpts.

## Cite every claim

- Put the source title and link next to every claim.
- Use the source's own wording. If the source says "can be", write "can be". Do not change "can be" to "is", or "usually" to "always".
- Use short quotes when the exact wording matters.

## Show what is uncertain

At the end of every research answer, list:

- **Conflicts**: where sources disagree, and who says what.
- **Gaps**: what you looked for and did not find.
- **Not checked**: anything you could not open, read, or verify, and why.

## No recommendations unless asked

- Do not recommend, rank, or decide unless the user asks you to.
- If you think a recommendation would help, say so in one line and wait.
- When the user does ask, keep the findings and the recommendation in separate sections.

## Where to save

- Save research findings in `_context/`. That folder is private and gitignored. Never copy it into `docs/`.
