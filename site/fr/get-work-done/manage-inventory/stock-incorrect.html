What happens if stock is incorrect?¤

When physical inventory doesn't match system records, you need to investigate and correct it.

Quick reference¤

Table 1. Common causes of stock discrepancies¤

Common cause What to check
Transaction errors Parts issued but not recorded, returns not processed
Physical issues Items misplaced, wrong bin locations, damaged items
System issues Data entry mistakes, incomplete transactions

💡 Tips for success¤

Daily habits:

  • Record transactions immediately
  • Verify before confirming
  • Return items promptly
  • Keep storeroom organized
  • Report issues quickly

Weekly tasks:

  • Review high-value items
  • Check reorder items
  • Spot check locations
  • Investigate variances
  • Update procedures

Monthly activities:

  • Analyze error patterns
  • Review adjustment reports
  • Conduct cycle counts
  • Train as needed
  • Improve processes

Why fix inventory errors quickly?¤

Inventory discrepancies can cause stockouts, excess inventory, and inaccurate costs.

Fixing errors quickly ensures:

  • Accurate records
  • No work delays
  • Reliable stock levels
  • Correct cost tracking

Regular counting and prompt adjustments keep your inventory data trustworthy.

What causes inventory errors?¤

Transaction errors¤

  • Parts issued but not recorded
  • Returns not processed
  • Wrong quantities entered
  • Duplicate transactions
  • Missing receipts

Physical issues¤

  • Items misplaced in storeroom
  • Wrong bin locations
  • Damaged or lost items
  • Theft or shrinkage
  • Items in wrong storeroom

System issues¤

  • Data entry mistakes
  • Timing differences
  • Incomplete transactions
  • System errors
  • Integration problems

How do I identify discrepancies?¤

During work¤

You might notice:

  • Item shows in stock but can't find it
  • Physical count doesn't match system
  • Bin is empty but system shows quantity
  • Wrong item in labeled bin
  • Unexpected items in storeroom

Through cycle counts¤

Regular counting reveals:

  • Quantity differences
  • Location errors
  • Missing items
  • Extra items
  • Condition issues

From reports¤

System reports show:

  • Negative balances (impossible physically)
  • Unusually high balances
  • No movement for long periods
  • Frequent adjustments
  • Cost variances

How do I investigate discrepancies?¤

Step 1: Verify the physical count¤

Before adjusting the system:

Recount the item:

  • Check all bins for this item
  • Look in nearby locations
  • Verify item number matches
  • Check for similar items

Check for reserved items:

  • Items in pick lists
  • Parts allocated to work orders
  • Items being transferred
  • Staged materials

Look for recent transactions:

  • Issues not yet processed
  • Returns in progress
  • Receipts being entered
  • Transfers pending

Step 2: Review transaction history¤

Check recent activity:

  • Issue transactions: Were parts recorded?
  • Receipts: Did everything get entered?
  • Returns: Were returns processed?
  • Transfers: Did transfers complete?
  • Adjustments: Previous corrections made?

Look for patterns:

  • Repeated errors with same item
  • Specific user or storeroom
  • Particular transaction type
  • Time of day issues occur

Step 3: Check related records¤

Verify:

  • Work orders: Materials recorded correctly?
  • Receipts: All delivered stock entered?
  • Inventory transfers: Transfers completed properly?
  • Issues: Items picked and issued from storeroom?

How do I correct inventory?¤

Make adjustments¤

Once you've verified the error:

What to do:

  1. Open the Inventory application.
  2. Find the item.
  3. Go to the storeroom with error.
  4. Use Adjust Balance action.
  5. Enter correct physical quantity.
  6. System calculates difference.
  7. Add reason for adjustment.
  8. Include detailed notes.

The system updates balance, adjusts cost, records transaction, and creates audit trail.

Adjustment best practices¤

Always document:

  • What you found
  • What you expected
  • Why the error occurred
  • Who discovered it
  • When it was found
  • Corrective action taken

Get approval if needed:

  • Large adjustments
  • High-value items
  • Frequent corrections
  • Unusual circumstances

Follow up:

  • Prevent recurrence
  • Train if needed
  • Improve processes
  • Monitor for patterns

Types of adjustments¤

Quantity adjustments¤

Increase balance:

  • Found items not recorded
  • Receipt was missed
  • Return not processed
  • Transfer not completed

Decrease balance:

  • Items issued but not recorded
  • Damaged or lost items
  • Theft or shrinkage
  • Items moved to another location

Location adjustments¤

Moving items:

  • Wrong bin recorded
  • Reorganizing storeroom
  • Consolidating locations
  • Correcting bin assignments

Cost adjustments¤

Correcting costs:

  • Wrong price entered
  • Cost method changed
  • Vendor price correction
  • Currency adjustments

How do I prevent inventory errors?¤

Good practices¤

At issue time:

  • Record transactions immediately
  • Verify quantities
  • Check item numbers
  • Confirm locations
  • Complete transactions fully

At receipt time:

  • Count carefully
  • Match to purchase order
  • Verify item numbers
  • Put in correct location
  • Record promptly

During returns:

  • Process immediately
  • Verify condition
  • Return to correct bin
  • Update system
  • Note any issues

Regular cycle counting¤

Count frequently:

  • High-value items weekly
  • Fast-moving items monthly
  • All items quarterly
  • Random spot checks

Count systematically:

  • Follow schedule
  • Use count books
  • Verify before adjusting
  • Document findings
  • Analyze patterns

Storeroom organization¤

Keep organized:

  • Clear bin labels
  • Logical layout
  • Similar items separated
  • Regular housekeeping
  • Defined locations

Control access:

  • Authorized personnel only
  • Proper training
  • Clear procedures
  • Accountability
  • Security measures

Handling specific scenarios¤

Negative balance¤

If system shows negative quantity:

  1. This shouldn't happen physically.
  2. Indicates transaction error.
  3. Review recent issues.
  4. Check for duplicate transactions.
  5. Correct immediately.
  6. Investigate cause.

Large discrepancy¤

For significant differences:

  1. Don't adjust immediately.
  2. Investigate thoroughly.
  3. Get supervisor approval.
  4. Document extensively.
  5. Implement prevention.
  6. Monitor closely.

Recurring errors¤

If same item has frequent issues:

  1. Analyze error pattern.
  2. Identify root cause.
  3. Fix process problem.
  4. Retrain if needed.
  5. Consider item changes.
  6. Monitor improvement.

What's the impact of inventory errors?¤

On operations¤

Stockouts:

  • Work delays
  • Emergency orders
  • Higher costs
  • Service issues

Excess inventory:

  • Wasted space
  • Tied-up cash
  • Obsolescence risk
  • Carrying costs

On costs¤

Direct costs:

  • Incorrect work order costs
  • Wrong inventory valuation
  • Budget variances
  • Financial reporting errors

Indirect costs:

  • Time investigating
  • Emergency purchases
  • Lost productivity
  • Customer dissatisfaction

On planning¤

Poor decisions:

  • Wrong reorder quantities
  • Incorrect stock levels
  • Bad purchasing decisions
  • Inefficient operations

When should I perform physical inventory?¤

Full physical count¤

Do complete inventory when:

  • Annual audit required
  • Major discrepancies found
  • System implementation
  • Storeroom reorganization
  • Change in responsibility

Cycle counting¤

Regular partial counts:

  • Less disruptive
  • Continuous accuracy
  • Catches errors early
  • Maintains reliability
  • Spreads workload

How do I use count books?¤

Count books help organize counting:

  • Group items logically
  • Schedule counts
  • Assign counters
  • Track completion
  • Record results
  • Analyze variances

The system can:

  • Generate count books
  • Assign to users
  • Track progress
  • Record counts
  • Calculate differences
  • Create adjustments

You create count books in the Count Books application, from Inventory > Count Books. You count items in the Inventory Counting app, from Inventory > Inventory Counting on the desktop or in IBM Maximo Mobile. In Inventory Counting, you can:

  • Count the items in a count book.
  • Count items that are not in a count book.
  • Count items and rotating assets.
  • Set tolerances that allow for small differences between the system balance and the physical count.
  • See alerts for differences that need a recount.
  • Count in batches as part of a cycle count.

After you count, you reconcile the counts to update the inventory balances.
