What can I do in my role?¤

Maximo Application Suite Select helps you manage maintenance work from start to finish.

Whether you're fixing equipment, tracking parts, or planning preventive maintenance, everything you need is in one place.

What can I do as a technician?¤

  • View your assigned work orders in the Technician app
  • Complete tasks and record what you did
  • Complete inspections in the Inspections app
  • Report time and materials used
  • Request parts from inventory
  • Add notes and photos to work orders
  • Complete work on the go with IBM Maximo Mobile

First task: Complete a work order

What can I do as a supervisor?¤

  • Create and assign work orders in the Work Orders application
  • Schedule preventive maintenance
  • Track work progress and completion
  • Monitor team workload
  • Review maintenance costs and performance
  • Assign and approve work on the go with IBM Maximo Mobile

First task: Assign and track work

What can I do as an inventory clerk?¤

  • Issue parts to work orders in the Issues and Transfers app
  • Track stock levels and locations
  • Receive new inventory
  • Perform stock counts in the Inventory Counting app
  • Monitor part usage
  • Issue parts and receive inventory on the go with IBM Maximo Mobile

First task: Issue a part

What can I do as an administrator?¤

  • Load user and asset data
  • Set up communication templates
  • Configure Artificial Intelligence (AI) features
  • Manage user access
  • Customize notifications
  • Configure IBM Maximo Mobile for field teams

First task: Load user data

What if I run into issues?¤

If you need help:

  1. For a specific field: Click the field name or press Alt+F1 to see field-level help.
  2. In the product: Click the help icon (?) in the top right corner.
  3. In these docs: Check the Get Answers section.
  4. Still stuck?: Submit feedback through the help menu.
