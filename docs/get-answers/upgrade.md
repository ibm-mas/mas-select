Create purchase requests for the materials and services you need, route purchases for approval, track what was ordered and received, and match invoices with the original transaction. For example, if you need to replace a valve on **Filler FL-02**, you can create a purchase request directly connected to that asset. ### How do purchase orders connect with work orders?

When a work order requires materials or services that are not immediately available, the requirement can feed into the purchasing process. Keeping purchases connected to work orders helps maintenance and procurement teams understand what is needed, where it is needed, and which work activity generated the cost.

### Can I connect purchase orders with an existing procurement system?

Yes, integration can exchange purchasing information with an existing procurement system, allowing each system to retain its role in the process. The integration depends on which system manages purchase requests, purchase orders, receipts, invoices, and related reference data.

Track maintenance costs using financial accounts to classify transactions, use budgets to help you monitor spending, and keep cost information connected to work orders, assets, or projects. For example, you can track the total maintenance spend on **Spiral freezer SF-01** against your annual facility budget. Support for financial periods, currencies, and exchange rates helps align maintenance activity with your organization’s financial structure.

### How are maintenance costs recorded against work orders?

As work progresses, the work order records the labor, materials, services, and tools used to complete it. Financial accounts classify related transactions, helping you understand what the work cost, where the cost was allocated, and which maintenance activity generated the expense.

### How can these features work with an existing enterprise resource planning system?

Integration connects maintenance activity with financial processes managed in your enterprise resource planning (ERP) system. Financial accounts and resource codes can be aligned across systems, while integration exchanges the transactions each system needs. The approach depends on which system owns each record and where financial processing takes place.

Graphical schedules and dashboards help planners organize upcoming work and balance workloads against available resources, while assignment and dispatching tools help match technicians and crews with the work based on skills, availability, and work requirements.

### How do Graphical Scheduling and Graphical Assignment differ?

Use Graphical Scheduling to determine when work should happen and how it fits into the overall maintenance schedule. Use Graphical Assignment to decide who should do the work, based on skills, availability, and other resource requirements. One builds the work plan, the other assigns the appropriate resources.

### When would I use the planning, scheduling, or dispatching dashboards?

Use the Planning dashboard to review work, resources, and costs when developing maintenance plans. Use the Scheduling dashboard to review upcoming work and resource utilization. Use the Dispatching dashboard to monitor assignments and respond when changing conditions affect scheduled work.

Apply a safety plan to a work order to include relevant hazards, precautions, hazardous materials, and tagout procedures in the work record. ### Can I connect an existing incident-management system?

Integration can exchange incident information with an existing system without requiring both systems to perform the same function. The approach depends on where records are managed, what information needs to be exchanged, and the capabilities of the existing system.

### How can predictive insights support maintenance work?

Predictive insights highlight assets with an increased probability of failure, including those that may need attention before their next scheduled preventive maintenance activity.
