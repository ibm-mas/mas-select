# Security

Find quick answers to common questions about security, access control, and data protection.

## Questions

### How do I control who can access the system?

Administrators create user accounts and assign security groups in the Users application and suite administration. Each user receives login credentials or accesses the suite through enterprise single sign-on.

[I want to know more about adding users](../get-work-done/setup-control/add-users.md)

### How do I manage user permissions?

Permissions are controlled through role-based security groups, such as Administrator, Supervisor, Technician, and Inventory Clerk. Security groups determine which desktop applications, role-based apps, and actions each user can access. Following the principle of least privilege, users are granted only the access required for their specific role.

[I want to know more about user permissions and security groups](../get-work-done/setup-control/add-users.md)

### How is my data protected?

Maximo Application Suite Select protects data through role-based access control, encrypted network transmission, and complete audit logging. Critical transactions, such as status changes, inventory balance adjustments, and work order actuals, record the user identifier and timestamp to maintain accountability.

### How do I set up single sign-on?

Enterprise single sign-on is configured at the suite administration level with standard identity providers, such as SAML 2.0 or OpenID Connect. Once single sign-on is enabled, users authenticate with their corporate credentials across both web browser sessions and IBM Maximo Mobile.

### What security features are available?

Security capabilities include role-based permissions, site-level data segregation, audit tracking, electronic signatures, secure session timeouts, and encrypted local data storage on mobile devices.
