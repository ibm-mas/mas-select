# Technicien : terminer votre premier ordre de travail { #technician-complete-your-first-work-order }

Démarrez rapidement avec une tâche conçue pour les techniciens comme vous. Apprenez les notions de base tout en accomplissant quelque chose d'utile.

Recherchez et terminez un ordre de travail qui vous est affecté, par exemple terminez le travail sur Filler FL-02.

![](../../images/guided_steps_final.png){ width="16" .no-lightbox } **Étapes guidées disponibles :**
Vous préférez apprendre dans l'application ? Connectez-vous et ouvrez votre Operational dashboard pour suivre les étapes guidées de réalisation d'un ordre de travail.

## 💡 Conseils pour réussir { #tips-for-success }

- Commencez par une tâche de maintenance préventive simple
- Demandez à votre superviseur en cas de doute
- Prenez des photos pour documenter votre travail
- Enregistrez les informations au fur et à mesure, et non à la fin

## Marche à suivre { #what-to-do }

1. Connectez-vous à Maximo Application Suite Select.
2. Accédez à Work Orders ou à My Assigned Work.
3. Choisissez un ordre de travail simple pour commencer (recherchez le statut "Assigned" ou "In Progress").
   <span class="see-also"><img src="../../../images/info_light_mode.png" class="no-lightbox info-icon" alt=""> <span class="see-also-text">Les ordres de travail sont nouveaux pour vous ? Lisez <a href="../basics/what-is-work-order.html">Qu'est-ce qu'un ordre de travail ?</a> pour comprendre les notions de base.</span></span>

4. Cliquez pour ouvrir les détails de l'ordre de travail.
5. Changez le statut en "In Progress".
6. Examinez ce qui doit être fait.
7. Vérifiez si vous avez besoin de pièces ou d'outils.
8. Effectuez la tâche de maintenance.
9. Ajoutez des notes sur ce que vous avez fait.
10. Enregistrez le temps passé (heures de main-d'œuvre).
11. Ajoutez les pièces que vous avez utilisées.
    <span class="see-also"><img src="../../../images/info_light_mode.png" class="no-lightbox info-icon" alt=""> <span class="see-also-text">Vous devez demander des pièces ? Consultez <a href="../../get-work-done/manage-inventory/issue-parts.html">Comment sortir des pièces pour un travail ?</a></span></span>

12. Mettez à jour les relevés de compteur, le cas échéant.
13. Changez le statut en "Completed".
14. Vérifiez que toutes les informations sont enregistrées.
15. Soumettez l'ordre de travail pour approbation si nécessaire.

## À quoi ressemble la réussite { #what-success-looks-like }

Vous avez terminé votre premier ordre de travail avec succès lorsque :

- Le statut de l'ordre de travail est passé de "Assigned" à "Completed"
- Toutes les zones obligatoires sont renseignées, comme les notes, les heures de main-d'œuvre ou les pièces utilisées
- Votre superviseur peut voir ce que vous avez fait et pourquoi
- L'historique de l'équipement affiche désormais votre travail
- L'inventaire des pièces est mis à jour automatiquement
- Le temps et les coûts sont enregistrés à des fins de planification

**Vous saurez que vous êtes prêt à passer à la suite lorsque** vous pouvez terminer un ordre de travail simple du début à la fin sans aide, et que vos notes expliquent clairement ce que vous avez constaté et réparé.

Pour plus de détails sur l'enregistrement précis des notes, des pièces et du temps, consultez [Comment terminer un ordre de travail ?](../../get-work-done/complete-work/complete-job.md)
