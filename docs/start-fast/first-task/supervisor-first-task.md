# Supervisor: Assign and track work

Get started quickly with a task designed for supervisors like you. Learn the basics while accomplishing something useful.

Assign a work order to a technician and track its progress, for example, assign preventive maintenance for Spiral freezer SF-01.

When work needs your approval, you can also approve it from IBM Maximo Mobile.

![](../../images/guided_steps_final.png){ width="16" .no-lightbox } **Guided steps available:**
Prefer to learn in the application? Log in and open your Operational dashboard to follow guided steps for assigning a work order.

## 💡 Tips for success

- Balance workload across your team
- Assign work based on skills and location
- Set clear expectations and deadlines
- Check in regularly on work progress
- Use dashboards to monitor team performance

## What to do

1. Log into Maximo Application Suite Select.
2. Go to **Work Orders > Work Orders**.
3. Filter for unassigned work orders.
4. Review priority and due dates.
5. Choose a work order that needs assignment.
6. Review the work details.
7. Check required skills or crafts.
8. Consider technician skills and current workload.
9. Verify technician availability.
10. Open the work order.
11. Add the technician to labor section.
12. Set expected start date.
13. Add any special instructions.
14. Save the assignment.
15. Monitor work order status for updates.
16. Review when work is completed.
17. Check labor hours and parts usage.
18. Approve if required.

## What success looks like

You've successfully assigned and tracked your first work order when:

- Work order shows assigned technician in labor section
- Technician can see the work order in their queue
- Start date and expectations are clear
- Work order progresses through statuses (Assigned → In Progress → Completed)
- You can monitor progress in real-time
- Work is completed on time with good documentation
- You can review and approve the completed work

**You'll know you're ready to move on when** you can assign work efficiently, balance workload across your team, and track multiple work orders simultaneously.
