# Inventory clerk: Issue a part

Get started quickly with a task designed for inventory clerks like you. Learn the basics while accomplishing something useful.

Issue a part from the storeroom to a work order, for example, issue parts from Main storeroom.

![](../../images/guided_steps_final.png){ width="16" .no-lightbox } **Guided steps available:**
Prefer to learn in the application? Log in and open your Operational dashboard to follow guided steps for issuing a part.

## 💡 Tips for success

- Always verify item numbers before issuing
- Keep storeroom organized and labeled
- Issue parts promptly to avoid work delays
- Record transactions immediately
- Check for reorder needs after issuing

## What to do

1. Check for work orders needing parts.
2. Review the parts list.
3. Note the work order number.
4. Go to Inventory application.
5. Search by item number or description.
6. Check the storeroom location.
7. Verify quantity available.
8. Go to the storeroom.
9. Find the correct bin location.
10. Verify the item number matches.
11. Check the part condition.
12. In Maximo, open the inventory record.
13. Click **Issue** action.
14. Enter the work order number.
15. Specify quantity to issue.
16. Confirm the transaction.
17. Check that inventory balance decreased.
18. Verify work order shows the material.
19. Confirm cost was recorded.
20. Hand over the physical part to technician.

## What success looks like

You've successfully issued your first part when:

- Inventory balance decreased by the correct quantity
- Work order shows the material issued with cost
- Transaction recorded with work order number
- Physical part delivered to technician
- Storeroom bin location updated if needed
- System and physical inventory match
- No errors or warnings in the transaction

**You'll know you're ready to move on when** you can issue parts quickly and accurately, verify inventory balances, and handle multiple requests efficiently.
