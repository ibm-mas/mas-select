# Administrateur : ajouter des utilisateurs { #administrator-add-users }

Démarrez rapidement avec une tâche conçue pour les administrateurs comme vous. Apprenez les notions de base tout en accomplissant quelque chose d'utile.

Ajoutez un nouvel utilisateur au système et accordez-lui les accès appropriés, par exemple ajoutez des utilisateurs pour Ice cream plant A.

## 💡 Conseils pour réussir { #tips-for-success }

- Utilisez des conventions de nommage cohérentes pour les ID utilisateur
- Appliquez le principe du moindre privilège, c'est-à-dire l'accès minimal nécessaire
- Gardez les affectations de groupes de sécurité organisées

## Préférences utilisateur { #user-preferences }

Les utilisateurs mettent à jour leurs préférences dans leur profil. Ils ouvrent le menu du profil en haut à droite de l'en-tête et peuvent sélectionner des préférences, comme une <abbr title="L'application qui s'ouvre lorsque vous vous connectez. Choisir la bonne application par défaut vous amène directement à l'écran le plus pertinent pour votre rôle, sans navigation supplémentaire.">application par défaut</abbr>, un magasin, des paramètres régionaux et une langue.

## À quoi ressemble la réussite { #what-success-looks-like }

Vous avez ajouté votre premier utilisateur avec succès lorsque :

- L'utilisateur peut se connecter
- L'utilisateur voit les applications et les menus appropriés
- Les droits du groupe de sécurité fonctionnent comme prévu
- L'utilisateur peut effectuer les tâches correspondant à son rôle
- Aucun message d'erreur ni problème d'accès

**Vous saurez que vous êtes prêt à passer à la suite lorsque** vous pouvez créer des utilisateurs efficacement, attribuer les droits appropriés et résoudre seul les problèmes d'accès.

## Et ensuite ? { #whats-next }

Après avoir créé votre premier utilisateur, essayez de :

- Configurer les notifications par e-mail
- Définir des groupes de sécurité supplémentaires
