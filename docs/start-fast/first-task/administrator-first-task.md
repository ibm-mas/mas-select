# Administrator: Add users

Get started quickly with a task designed for administrators like you. Learn the basics while accomplishing something useful.

Add a new user to the system and assign them appropriate access, for example, add users for Ice cream plant A.

## 💡 Tips for success

- Use consistent naming conventions for user IDs
- Follow principle of least privilege, that is, minimum access needed
- Keep security group assignments organized

## What to do

## User preferences

Users update their preferences in their profile. They open the profile menu from the top right of the header and can select preferences, such as a <abbr title="The application that opens when you log in. Choosing the correct default means you land on the most relevant screen for your role without extra navigation.">default application</abbr>, storeroom, locale, and language.

## What success looks like

You've successfully added your first user when:

- User can log in successfully
- User sees appropriate applications and menus
- Security group permissions work as expected
- User can perform tasks for their role
- No error messages or access issues

**You'll know you're ready to move on when** you can create users efficiently, assign appropriate permissions, and troubleshoot access issues independently.

## What's next?

After creating your first user, try:

- Configuring email notifications
- Setting up additional security groups
