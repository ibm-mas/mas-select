# What keyboard shortcuts can I use?

You can use keyboard shortcuts to work faster in Maximo Application Suite Select without switching between your keyboard and mouse.

---

## Everyday actions

Use these shortcuts throughout the application for saving, navigating records, and changing status.

### Table 1. Keyboard shortcuts for everyday actions

| Action | Keyboard shortcut |
|--------|------------------|
| Insert new record | Ctrl+Alt+I |
| Save record | Ctrl+Alt+S |
| Clear changes | Ctrl+Alt+C |
| Previous record | Ctrl+Alt+P |
| Next record | Ctrl+Alt+N |
| Change status | Ctrl+Alt+A |
| Put record in edit mode, or release record from edit mode | Ctrl+Alt+L |

---

## Navigating the page

Use these shortcuts to move through fields, select controls, and get contextual help.

### Table 2. Keyboard shortcuts for page navigation

| Action | Keyboard shortcut |
|--------|------------------|
| Move to the next field or control | Tab |
| Select a button, link, or menu option | Enter |
| Select or clear a check box | Spacebar |
| Show a description of the selected field | Alt+F1 |

!!! tip "Mac users"
    On a Mac, press **Option+Fn+F1** to show a description of the selected field.

---

## Working in tables

Use these shortcuts when you are entering data in a table, such as adding job plan tasks or labor assignments.

### Table 3. Keyboard shortcuts for tables

| Action | Keyboard shortcut |
|--------|------------------|
| Move to the next row | Ctrl+Down arrow |
| Move to the previous row | Ctrl+Up arrow |
| Create a new row | Enter |
| Submit a value | Tab |
| Open or close the table filter | Ctrl+Z |
| Move to the next page | Ctrl+Right arrow |
| Move to the previous page | Ctrl+Left arrow |

---

## Working with dates

Use these shortcuts when entering or adjusting dates in date fields.

### Table 4. Keyboard shortcuts for dates

| Action | Keyboard shortcut |
|--------|------------------|
| Insert today's date | Ctrl+Shift+7 |
| Move forward one day | Alt+Up arrow |
| Move back one day | Alt+Down arrow |
| Move forward one month | Ctrl+Shift+0 |
| Move back one month | Ctrl+Shift+9 |
| Move forward one year | Ctrl+Shift+Up arrow |
| Move back one year | Ctrl+Shift+Down arrow |

---

## Global navigation

Use these shortcuts to return from lookup windows.

### Table 5. Keyboard shortcuts for global navigation

| Action | Keyboard shortcut |
|--------|------------------|
| Return | Alt+R |
| Return with value | Alt+W |

---

## Non-standard behaviour

Two keyboard shortcuts behave differently in Maximo Application Suite Select from the standard browser expectation. Knowing this prevents confusion.

### Table 6. Non-standard keyboard shortcut behaviour

| UI element | What you would normally expect | What happens instead |
|------------|-------------------------------|----------------------|
| Radio buttons | Pressing the right or left arrow key selects the radio button as you move through the options. | Radio buttons are highlighted but not selected as you move through them. Press **Spacebar** or **Enter** to select the highlighted option. |
| Tree view | Pressing **Enter** on a node performs its default action. | Nodes can have up to two actions. If you press **Enter** once, the default action runs. If you press **Enter** a second time, the secondary action runs. |
