# What are the basic concepts?

Understanding a few key concepts helps you work more effectively in Maximo Application Suite Select. These are the building blocks you'll use every day.

## Quick reference

### Table 1. Core concepts

| Concept | What it is | Example |
|---------|------------|---------|
| **Location** | Where work happens | Filling Line 2 |
| **Asset** | Equipment you maintain | Filler FL-02 |
| **Work order** | Instruction to do work | Inspect filler nozzles |
