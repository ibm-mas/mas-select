# Qu'est-ce qu'un actif ? { #what-is-an-asset }

Un actif est tout équipement, toute machine ou toute infrastructure que votre organisation entretient. Les actifs sont les éléments physiques sur lesquels vous travaillez.

## Exemples d'actifs { #examples-of-assets }
- **Équipements de production** : Batch Mixer MX-01, Filler FL-02, Conveyor CV-02, Spiral Freezer SF-01
- **Équipements de procédé** : pompes, moteurs, compresseurs, échangeurs de chaleur, refroidisseurs
- **Installations** : systèmes de chauffage, ventilation et climatisation, unités de réfrigération, systèmes d'éclairage
- **Véhicules** : camions, chariots élévateurs, transpalettes
- **Stockage** : cuves, silos, chambres froides

## Pourquoi les actifs sont importants { #why-assets-matter }
- Suivre l'historique de maintenance de chaque équipement
- Planifier la maintenance préventive
- Surveiller l'état et les performances des actifs
- Planifier les remplacements et les mises à niveau
- Calculer le coût total de possession

Un actif est un équipement physique que vous entretenez. Vous pouvez organiser les actifs selon une hiérarchie parent-enfant afin de montrer comment les équipements sont reliés et de suivre la maintenance au bon niveau.

Dans la figure 1, Batch Mixer MX-01, Filler FL-02, Conveyor CV-02 et Spiral Freezer SF-01 sont des actifs parents. Les actifs parents peuvent inclure des actifs enfants. Par exemple, Batch Mixer MX-01 comprend l'Agitator motor et le Seal.

Les actifs sont installés dans des emplacements, qui indiquent où l'équipement fonctionne.

L'utilisation de hiérarchies d'actifs présente de nombreux avantages :

- Comprendre comment les équipements sont reliés
- Suivre la maintenance d'un système complet ou d'un composant précis
- Voir à la fois ce qu'est l'équipement et où il est installé

Vous souhaitez voir comment cela s'articule avec les emplacements et les ordres de travail ? Consultez [Comment les emplacements, les actifs et les ordres de travail fonctionnent-ils ensemble ?](how-concepts-work-together.md)

## Nommer les actifs { #naming-assets }

**✓ À faire**

- Utilisez un numéro d'actif alphanumérique court
- Rédigez une description claire et précise
- Utilisez un format de description cohérent
- Identifiez l'actif parent lorsque c'est pertinent

**✗ À éviter**

- N'utilisez pas de descriptions vagues telles que PUMP
- Ne surchargez pas le numéro d'actif avec trop de détails

**Exemples d'actifs** : Batch Mixer MX-01, Filler FL-02, Conveyor CV-02, Spiral Freezer SF-01.

**Exemples de descriptions** : Filler FL-02, poste de remplissage de cornets ; Batch Mixer MX-01, préparation du mélange vanille.
