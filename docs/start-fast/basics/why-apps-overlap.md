# Why can I manage work orders in more than one place?

You can work with work orders in three places:

- The Work Orders application.
- The Technician app on the desktop, in your web browser.
- The Technician app in IBM Maximo Mobile, on your phone or tablet.

All three work with the same work orders.

This happens because Maximo Application Suite Select includes two kinds of apps:

- **Desktop applications**, such as Work Orders, Assets, and Inventory. These are the full applications that match the rest of the interface.
- **Mobile apps**, such as Technician, Inspections, and Asset Manager. Each is one application with two versions: a web version that runs in your browser next to the desktop applications, and a mobile version that runs in IBM Maximo Mobile on your phone or tablet. The two versions work the same way. Only the mobile version works offline.

The two kinds of apps do not match one for one. For example, Technician combines parts of several desktop applications into one app for completing work.

Most of the menu is desktop applications. To tell the two kinds apart, look at the name in the menu:

- The web version of a mobile app has a label in parentheses after its name, such as **Timesheet (Mobile)** or **My Schedule (Mobile)**. In a narrow menu, the label is cut off, as in **Inventory Counting (M...**.
- A desktop application has no label, such as **Work Orders** or **Count Books**.

Some mobile apps are grouped under a name such as Technician or Asset Manager. The group has no label, but the apps inside it do.

## Which one should I use?

There is no fixed rule. Use the one that suits how you work:

- If you use IBM Maximo Mobile often, use the web version of apps such as Technician on the desktop too. The app works the same way in both places.
- If you rarely use IBM Maximo Mobile, you might prefer desktop applications such as Work Orders. They are more consistent with the rest of the interface.

## How do I get back to the desktop applications?

The web version of a mobile app, such as Technician or Inspections, opens without the desktop menu. To go back to the desktop applications, select the application menu icon ![Application menu icon](../../images/application_menu_icon.png){ width="24" .no-lightbox } at the bottom right of the screen, then select **Start Center** or **Operational Dashboard** in the navigator.

## Quick reference

### Table 1: Mobile apps and what they do

| App | Use it to |
|-----|-----------|
| **Technician** | Complete assigned work. |
| **Inspections** | Complete inspections. |
| **Inspection Forms** | Work with inspection forms. |
| **Asset Manager** | Look up and manage assets. |
| **Issues and Transfers** | Issue and transfer inventory. |
| **Inventory Counting** | Count inventory. |
| **Service Requests** | Create and track service requests. |

To find any app, use the **Find navigation item** field at the top of the menu and search for the app name.

## Which apps can I see?

The apps you see depend on the security group that your administrator assigned to you. For the security groups, see [How do I add users?](../../get-work-done/setup-control/add-users.md)

!!! note
    Technician is both a security group and an app. The Technician security group is a role that you assign to a user. The Technician app is one of the apps that role can use.
