Upgrading from Maximo Application Suite Select¤

Find quick answers to common questions about the features and capabilities available when you upgrade.

Purchase orders¤

What purchase order features are available with an upgrade?¤

Example scenario: "I wish I could create a PR that is directly connected to this filler valve."

Maintenance technician

The Solution: Link your purchase requests directly to physical asset records on the fly. This connects maintenance needs immediately to procurement data, getting you the correct parts faster.

Create purchase requests for the materials and services you need, route purchases for approval, track what was ordered and received, and match invoices with the original transaction. For example, if you need to replace a valve on Filler FL-02, you can create a purchase request directly connected to that asset. This gives maintenance and procurement teams a clearer view of each purchase from request through receipt.

How do purchase orders connect with work orders?¤

When a work order requires materials or services that are not immediately available, the requirement can feed into the purchasing process. Keeping purchases connected to work orders helps maintenance and procurement teams understand what is needed, where it is needed, and which work activity generated the cost.

Can I connect purchase orders with an existing procurement system?¤

Yes, integration can exchange purchasing information with an existing procurement system, allowing each system to retain its role in the process. The integration depends on which system manages purchase requests, purchase orders, receipts, invoices, and related reference data.

Financials¤

What financial features are available with an upgrade?¤

Example scenario: "When I issue parts to a job, I want the cost to land on the right account."

Inventory clerk

The Solution: Classify costs with financial accounts and keep them connected to work orders and assets. You can see where each cost was allocated and which job generated it.

Track maintenance costs using financial accounts to classify transactions, use budgets to help you monitor spending, and keep cost information connected to work orders, assets, or projects. For example, you can track the total maintenance spend on Spiral freezer SF-01 against your annual facility budget. Support for financial periods, currencies, and exchange rates helps align maintenance activity with your organization’s financial structure.

How are maintenance costs recorded against work orders?¤

As work progresses, the work order records the labor, materials, services, and tools used to complete it. Financial accounts classify related transactions, helping you understand what the work cost, where the cost was allocated, and which maintenance activity generated the expense.

How can these features work with an existing enterprise resource planning system?¤

Integration connects maintenance activity with financial processes managed in your enterprise resource planning (ERP) system. Financial accounts and resource codes can be aligned across systems, while integration exchanges the transactions each system needs. The approach depends on which system owns each record and where financial processing takes place.

Planning and scheduling¤

What scheduling features are included with an upgrade?¤

Example scenario: "I can see all the open work, but I can't tell who is free to take it on."

Maintenance supervisor

The Solution: Use Graphical Assignment to match technicians and crews to work based on skills and availability. You can see who is free before you dispatch the job.

Graphical schedules and dashboards help planners organize upcoming work and balance workloads against available resources, while assignment and dispatching tools help match technicians and crews with the work based on skills, availability, and work requirements.

How do Graphical Scheduling and Graphical Assignment differ?¤

Use Graphical Scheduling to determine when work should happen and how it fits into the overall maintenance schedule. Use Graphical Assignment to decide who should do the work, based on skills, availability, and other resource requirements. One builds the work plan, the other assigns the appropriate resources.

When would I use the planning, scheduling, or dispatching dashboards?¤

Use the Planning dashboard to review work, resources, and costs when developing maintenance plans. Use the Scheduling dashboard to review upcoming work and resource utilization. Use the Dispatching dashboard to monitor assignments and respond when changing conditions affect scheduled work.

Safety¤

What safety features are available with an upgrade?¤

Example scenario: "Before I open this mixer, I need to know the exact lockout steps and what protective gear to wear."

Maintenance technician

The Solution: Apply a safety plan to the work order so hazards, precautions, and tagout procedures appear in the work record. You can review them while you plan and perform the job.

Include hazards, precautions, permits, and tagout procedures in maintenance planning and work performance. Keeping incident and near-miss information connected to the operational context in which it occurred makes relevant safety information easier to access and review.

How does safety information connect with work orders?¤

Apply a safety plan to a work order to include relevant hazards, precautions, hazardous materials, and tagout procedures in the work record. For example, before technicians service a high-voltage mixer, the work order can automatically display the required lockout-tagout (LOTO) steps and required personal protective equipment (PPE). Teams can reference safety information while planning and performing maintenance. Configured workflows can add review or approval steps where required.

Can I connect an existing incident-management system?¤

Integration can exchange incident information with an existing system without requiring both systems to perform the same function. The approach depends on where records are managed, what information needs to be exchanged, and the capabilities of the existing system.

Asset health insights¤

What asset health features are available with an upgrade?¤

Example scenario: "I want to know which compressor is likely to fail before it stops the line."

Maintenance supervisor

The Solution: Use health scores and predictive insights to see which assets have an increased probability of failure. Then decide whether to inspect the asset or adjust planned maintenance.

Bring asset condition, criticality, and risk together to identify assets that need attention. Health scores and work queues help teams prioritize reviews, while advanced analysis can reveal failure patterns and support maintenance and asset decisions.

How can predictive insights support maintenance work?¤

Predictive insights highlight assets with an increased probability of failure, including those that may need attention before their next scheduled preventive maintenance activity. For example, predictive models can analyze temperature fluctuations on Spiral freezer SF-01 and alert you to an impending compressor failure. Teams can review supporting data, consider asset risk and criticality, and decide whether to inspect the asset or adjust planned maintenance.

What data do I need to get started with asset health insights?¤

Start with reliable asset and maintenance information already available in your system. Installation dates, replacement costs, criticality, meter readings, inspections, work orders, and maintenance history can support different insights. The data required depends on the health scores and predictive models you want to use.

System configuration¤

What configuration features are available with an upgrade?¤

Example scenario: "I need to test a workflow change before it reaches the people who use it every day."

System administrator

The Solution: Develop and test configuration changes outside production, then move supported changes between environments in a controlled way. Your team can review and verify each change before it reaches users.

Configure workflows, applications, and business rules to support your organization's operational processes. Administrators can guide records through defined workflows, tailor parts of the user experience, automate selected actions, and move supported configuration changes between environments.

How can workflow changes be governed and reviewed?¤

Build workflows around defined decisions, actions, assignments, and notifications. Administrators can validate the design, test workflow paths, and make adjustments before introducing changes to production. Access controls and your organization’s review process help govern those changes.

How can I test and move configuration changes between environments?¤

Develop and test changes outside production, then package supported configuration content for controlled movement between environments. A typical process moves changes from development to test and then to production, allowing teams to review and verify changes before they reach users.
